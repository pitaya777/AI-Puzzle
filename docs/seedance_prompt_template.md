# Seedance 2.5 校园回忆视频提示词模板

此模板由 DeepSeek 根据用户的四段回忆填写，最终内容原样传给 Doubao-Seedance-2.5。

## 整体风格

说明动画或电影语言、色彩、光线、材质、景深、节奏，以及温暖怀旧的校园回忆气质。

## 角色与连续性

参考 `@图像1`，锁定主角外观、服装、画风、道具和校园空间。明确所有镜头属于同一人物、同一事件，动作、视线、位置和光线前后承接。

## 分时段导演脚本

- 0-3 秒：建立校园环境和开头，用晨光、风吹树叶、旧照片感或主角回望引入回忆。
- 3-7 秒：由主角动作触发回忆，进入校园生活。
- 7-11 秒：呈现地点与人物关系。
- 11-16 秒：继续同一行动，表现陪伴。
- 16-21 秒：出现成长或情绪转折。
- 21-25 秒：回应写给过去自己的话。
- 25-30 秒：回应开头，以校园远景、同行、回望或走向光亮完成升华。

每个时间段均填写：画面、表演、镜头、背景音乐、环境/动作音效、旁白和转场。

## 声音

背景音乐使用原创、无歌词的钢琴与轻柔弦乐，由轻柔怀旧逐渐丰盈；25～30秒达到温暖明亮的情绪高点。全片固定为同一位年轻温柔的中文女声，语速舒缓、吐字清晰，每句旁白严格放在指定时间段内。保留自然校园环境音，音乐不得遮盖旁白。

## 画面文字

当前版本不生成字幕。提示词必须明确禁止字幕、标题、标志、水印和其他画面文字。

## 禁止项

禁止问卷或问题图解、拼贴、分屏、无关场景、突然更换角色造型、品牌广告、乱码、水印和多余文字。
