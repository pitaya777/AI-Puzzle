# 拾光校园（AI puzzle）

响应式校园记忆创作应用。访客上传一张照片，系统先生成不可识别身份的原创漫画角色图；用户完成3×3拼图与四段回忆问答后，由 DeepSeek 整理故事和连续分镜，再调用 Seedance 2.5 生成30秒竖屏纪念视频。作品可下载或生成可撤销分享链接，后台展示访问与分享统计。

## 启动

Windows双击 `start.cmd`，或在PowerShell运行：

```powershell
.\start.ps1
```

浏览器访问 `http://127.0.0.1:8001`。后台密码首次启动后生成在 `data/admin-password.txt`。停止服务运行 `stop.cmd`。

默认无需Docker、MySQL或系统FFmpeg；首次启动自动创建Python环境并安装依赖。数据写入 `data/`。访客作品与浏览器Cookie绑定，清除Cookie后无法找回，请及时下载。

## AI与音乐配置

首次启动会把 `.env.example` 复制为 `.env`。请在本机 `.env` 中配置 DeepSeek、Seedream 与 Seedance 的密钥和模型ID，模型ID以火山方舟控制台实际开放值为准。系统传给 Seedance 的首帧是 Seedream 生成的原创漫画角色图；如账户或素材策略仍要求可信素材，也可填写可选的 `SEEDANCE_ASSET_ID`。填写配置并重启后生效，切勿提交 `.env`。

真实视频生成需要完整配置三项AI服务，并把 `REAL_JOB_RESERVE_RMB` 设置为大于0的单次费用预留值。程序不会把密钥发送到前端或写入仓库。

## 已实现范围

- JPG/PNG单图上传，最大5MB，9:16焦点裁剪
- 固定3×3拼图，碎片顺序随机打乱
- 25%、50%、75%、100%四阶段必答，每题100字
- 拼图、答案和任务状态持久化；生成任务可离页继续
- 作品列表、播放、下载、关联删除
- 分享链接生成与撤销，撤销后视频直链失效
- 访客数据隔离、后台独立密码、访问与分享统计
- Seedream将真人照片改编为不可关联身份的原创漫画角色首帧
- DeepSeek生成覆盖0～30秒的连续叙事提示词
- 一次调用Doubao-Seedance-2.5直出30秒校园回忆视频，包含明确开头、连续分镜、升华结尾、原创背景音乐和温柔中文女声旁白；当前不生成字幕
- 真实生成每天最多3次，项目费用预留上限300元

真实API能否成功由账户权限、模型ID、余额和服务商限制决定。服务未配置时，界面会明确提示，项目不会用本机视频替代Seedance输出。
